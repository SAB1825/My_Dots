# Niri migration

This overlay retains Zsh, Kitty, Fastfetch (including gojo.png), and tmux from
this repository. The original Hyprland and Quickshell files remain in Git.
The current shell is https://github.com/shadowww-dev/DarkShadowShell.
This is a selective migration, not a complete backup of the new shell.

Niri config.kdl is generated by rice-niri. Edit niri/user.kdl for persistent
custom rules. rice/hypr.json is also used for Niri despite its name: rice-niri
translates the old blur size 8 into offset 2.67, passes 3, noise 0, saturation 1.
Kitty opacity is 0.92; whole-window opacity stays at 1 to keep text solid.
The current corner radius 22 is preserved. Hyprland and Niri blur are approximate
visual matches. Existing Nautilus translucency is retained.

Tmux keeps the backtick prefix, key bindings, and wallpaper colors. Its palette
helper reads rice/palette.json, with the old Matugen cache as a fallback.
Missing plugins are skipped until initialized. Optional bindings require sesh,
gum, fzf, fd, zoxide, yazi, lazygit, rmpc, and ~/scripts/tmux-sessionizer.sh.

## Finish on this machine

Run the prepared apply-to-repo.sh to copy the reviewed overlay into the existing
repository and link ~/.zshrc. It backs up overwritten files and does not commit
or push. It leaves unrelated repository files in place.

Install required applications if missing:

    sudo pacman -S --needed zsh tmux zsh-autosuggestions zsh-syntax-highlighting

Populate the repository's existing plugin submodules:

    git -C ~/Temporary/dotfiles submodule update --init --recursive

Then populate the live plugin directory (after checking it has no local plugins):

    cp -a ~/Temporary/dotfiles/config/tmux/.tmux/plugins/. ~/.config/tmux/.tmux/plugins/

Kitty launches Zsh with ZDOTDIR=$HOME/.config/zsh once installed, and uses Bash
until then. The prepared Zsh file is already in ~/.config/zsh/.zshrc. Updating
repository .zshrc later also requires updating that copy. No login-shell change
has been made. Restart Kitty to load its new shell and configuration.

Validation: installed Niri accepts the generated config; installed Fastfetch
loads the restored config with image output disabled for the check. Zsh and tmux
could not be executed because they are not currently installed.
